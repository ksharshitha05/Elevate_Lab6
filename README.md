# Linear Regression – House Price Prediction

## Objective
Build and evaluate a Linear Regression model to predict house prices using the California Housing dataset.

## Steps Performed
- Loaded and inspected dataset
- Split data into train and test sets
- Trained Linear Regression model
- Evaluated using MAE and RMSE
- Visualized Actual vs Predicted values
- Interpreted model coefficients

## Results
- MAE and RMSE saved in reports folder
- Predictions and plots saved automatically

## Tools Used
Python, Pandas, NumPy, Scikit-learn, Matplotlib

## Outcome
Built a complete regression pipeline with evaluation and interpretation.
